# Autoban

Android-приложение, которое сбрасывает и банит спам-звонки по настраиваемым правилам, ведёт журнал и присылает события в Telegram.

Работает через системный фильтр звонков (`CallScreeningService` + роль «Фильтр звонков»), поэтому не нужно делать его звонилкой по умолчанию и держать в фоне. Нужен Android 10 или новее.

## Установка

1. Соберите APK (`gradlew assembleDebug`) или возьмите готовый: `app/build/outputs/apk/debug/app-debug.apk`.
2. Установите на телефон (разрешите установку из неизвестных источников).
3. Откройте **Настройки** в приложении → **Назначить** (роль «Фильтр звонков») и **Разрешить** (доступ к SIM).
4. Если стоит другой определитель номера (GetContact, Truecaller и т.п.), отключите у него роль фильтра — она может быть только у одного приложения.

## Как это работает

Каждый входящий звонок не из контактов проверяется по порядку:

1. **Белый список** — номер всегда пропускается.
2. **Бан-лист** — номер сбрасывается на любой SIM.
3. **Правила** сверху вниз (по приоритету) — срабатывает первое подходящее.
4. Ничего не подошло — звонок пропускается.

Звонки из контактов система фильтру не показывает — они всегда проходят.

### Правила

Правило — набор условий (все должны выполниться) и действие: **пропустить**, **сбросить** или **сбросить и забанить** (номер попадает в бан-лист).

Условия:

| Условие | Пример |
|---|---|
| SIM | SIM1 / SIM2 |
| Номер скрыт / передан | — |
| Имя от сети по маске | `*ростелеком*`, `*` — любое имя, `re:ростел[её]к` — регулярка |
| Номер по маске | `+7495*`, `8800*`, `+7912???????` |
| Время и дни | пн–пт 09:00–18:00, через полночь 22:00–07:00 |
| Повторный звонок | 2-й звонок за 3 минуты (исключение «видимо, срочно») |

Маски: `*` — любые символы, `?` — один символ, регистр не важен, `ё` = `е`.

Новое правило создаётся в режиме **dry-run**: оно ничего не сбрасывает, только пишет в журнал «сработало бы». Когда убедились, что срабатывает правильно, включите **боевой режим** в редакторе.

Предустановлены два правила (в dry-run):

- **Скрытые на SIM1**: SIM1 и номер скрыт → сбросить.
- **Маркированные на SIM2**: SIM2 и номер передан и имя `*ростелеком*` → сбросить и забанить.

Кнопка **«Проверить звонок»** на вкладке «Правила» показывает, что произойдёт с вымышленным звонком.

### Журнал

Все проверенные звонки: время, SIM, номер, имя от сети, решение и правило. Фильтры по действию и SIM, поиск. В карточке звонка — «Разбанить», «В белый список», «Правило по звонку». Сводка за день и неделю — над журналом. Экспорт в CSV и резервная копия правил и списков (JSON) — в настройках.

### Telegram

1. Создайте бота у [@BotFather](https://t.me/BotFather), скопируйте токен.
2. Напишите своему боту любое сообщение.
3. В приложении: **Настройки → Telegram** → вставьте токен → **Найти** (chat_id подставится сам) → включите переключатель → **Сохранить** → **Тест**.

Можно выбрать, о чём сообщать (сбросы и баны, dry-run, все пропущенные), режим «сразу» или «сводкой раз в N минут», прокси HTTP/SOCKS5. Без сети сообщения ждут в очереди. Токен хранится зашифрованным ключом Android Keystore.

## Разработка

- Kotlin, Jetpack Compose (Material 3), SQLite, WorkManager, kotlinx.serialization.
- `gradlew testDebugUnitTest` — unit-тесты движка правил, масок, форматирования.
- Эмулятор: `adb shell cmd role add-role-holder android.app.role.CALL_SCREENING com.blkdem.autoban`, затем `adb emu gsm call 89991234567`.
- Секреты (токен бота для ручных проверок) — только в `.env`, он в `.gitignore`.
