# Autoban

Android-приложение, которое сбрасывает и банит спам-звонки по настраиваемым правилам, ведёт журнал и присылает события в Telegram.

Работает через системный фильтр звонков (`CallScreeningService` + роль «Фильтр звонков»), поэтому не нужно делать его звонилкой по умолчанию и держать в фоне. Нужен Android 10 или новее.

## Установка

1. Скачайте `autoban-<версия>.apk` со страницы [Releases](https://github.com/BlkDem/autoban/releases) или соберите сами (см. «Разработка»).
2. Установите на телефон (разрешите установку из неизвестных источников).
3. Откройте **Настройки** в приложении → **Назначить** (роль «Фильтр звонков») и **Разрешить** (доступ к SIM).
4. Если стоит другой определитель номера (GetContact, Truecaller и т.п.), отключите у него роль фильтра — она может быть только у одного приложения.

**Переход с тестовой сборки.** Релиз подписан другим ключом, поэтому поверх отладочной сборки (`app-debug.apk`) он не встанет. Если правила и списки нужно сохранить, сделайте резервную копию (Настройки → резервная копия) или отправьте их через бота, затем удалите старую версию, поставьте релиз и восстановите данные.

## Как это работает

Каждый входящий звонок не из контактов проверяется по порядку:

1. **Белый список** — номер всегда пропускается.
2. **Бан-лист** — номер сбрасывается на любой SIM.
3. **Правила** сверху вниз (по приоритету) — срабатывает первое подходящее.
4. Ничего не подошло — звонок пропускается.

Звонки из контактов система фильтру не показывает — они всегда проходят.

### Правила

Правило — набор условий (все должны выполниться) и действие: **пропустить**, **сбросить** или **сбросить и забанить** (номер попадает в бан-лист).

Условия:

| Условие | Пример |
|---|---|
| SIM | SIM1 / SIM2 |
| Номер скрыт / передан | — |
| Имя от сети по маске | `*ростелеком*`, `*` — любое имя, `re:ростел[её]к` — регулярка |
| Номер по маске | `+7495*`, `8800*`, `+7912???????` |
| Время и дни | пн–пт 09:00–18:00, через полночь 22:00–07:00 |
| Повторный звонок | 2-й звонок за 3 минуты (исключение «видимо, срочно») |
| Репутация по отзывам | не меньше 3 отзывов, оценка не выше 2, тип `*мошен*` |
| Маркировка оператора | организация `*ростелеком*`, категория `*реклам*` |
| Звонок без маркировки | подпись оператора «Звонок без маркировки» |

Маски: `*` — любые символы, `?` — один символ, регистр не важен, `ё` = `е`. Маски имён понимают транслитерацию: `*ростелеком*` совпадает и с `PAO Rostelekom: svyaz`.

Правило без условия SIM действует на любой SIM.

Новое правило создаётся в режиме **dry-run**: оно ничего не сбрасывает, только пишет в журнал «сработало бы». Когда убедились, что срабатывает правильно, включите **боевой режим** в редакторе.

Предустановлены три правила (в dry-run):

- **Скрытые на SIM1**: SIM1 и номер скрыт → сбросить.
- **Маркировка «Ростелеком»**: номер передан и имя `*ростелеком*` → сбросить и забанить. На любой SIM.
- **Плохие отзывы**: не меньше 3 отзывов и оценка не выше 2 → сбросить.

Кнопка **«Проверить звонок»** на вкладке «Правила» показывает, что произойдёт с вымышленным звонком.

### Подпись оператора и сброс из Telegram

С 1 сентября 2025 года операторы подписывают звонки организаций (41-ФЗ): «Ростелеком: связь» у Билайна, `PAO MTS: svyaz i internet` у МТС. Подпись приходит, когда телефон уже звонит, и в фильтр звонков не попадает. Поэтому пропущенный фильтром звонок Autoban сопровождает до конца:

- **Читает подпись из уведомления звонилки.** Если её ловит правило (имя по маске, «Маркировка оператора», «Звонок без маркировки»), звонок сбрасывается через секунду-две, номер банится, если так велит правило.
- **Присылает в Telegram сообщение, пока телефон звонит**: подпись, отзывы о номере и кнопки **⛔ Сбросить**, **🚫 Бан** (бан и сброс), **✅ Белый**. Пока звонок идёт, телефон слушает бота непрерывно — кнопка срабатывает сразу. Сообщение уходит через 3–4 секунды после начала звонка (ждём подпись и отзывы) и обновляется, когда звонок закончится: принят, не отвечен, сброшен.
- **После звонка** берёт подпись из журнала вызовов и записывает её в журнал Autoban.

Нужны три разрешения — **Настройки → Подпись оператора и сброс**: «Доступ к уведомлениям», «Управление звонками», «Журнал вызовов». Чтобы сообщение приходило о каждом входящем, включите в настройках Telegram фильтр «разрешённые звонки».

**Лучше всего — системный лог.** Samsung пишет подпись в системный лог раньше, чем звонок попадает в фильтр. С разрешением на чтение лога Autoban видит подпись сразу, и звонок, который ловит правило, сбрасывается до того, как телефон зазвонит. Разрешение выдаётся один раз с компьютера (телефон подключён по USB, включена отладка):

```
adb shell pm grant com.blkdem.autoban android.permission.READ_LOGS
```

Оно сохраняется при обновлениях, пропадает только при удалении приложения.

### Пробивка номера

При звонке не из контактов приложение ищет отзывы о номере на [zvonili.com](https://zvonili.com): оценку, число отзывов, тип номера («Мошенники», «Реклама», «Коллекторы»…), оператора, регион и последние отзывы. Сводка попадает в журнал, в карточку звонка и в сообщение Telegram, которое приходит, пока телефон ещё звонит. Пример:

```
📞 ВХОДЯЩИЙ · SIM1
+7 961 871-93-70
⚠️ 1.35/5 · 7631 отзыв · Неадекваты, Мошенники, Реклама
ПАО "Вымпел-Коммуникации" · Новосибирская обл.
💬 13.04.2026: Звонит губошлёп (Мошенники)
```

- **Звонок не задерживается.** Решение принимается сразу, поиск идёт после него. Правила в dry-run пересчитываются, когда сводка готова.
- **Боевое правило по репутации** ждёт отзывов до решения, но не дольше 3 секунд. Если сайт не успел, звонок проходит, а в журнале появляется «сработало бы … (отзывы пришли позже)». Повторный звонок решается по кэшу мгновенно.
- **Кэш.** Номера с отзывами перепроверяются раз в 3 дня, без отзывов — раз в сутки. В карточке звонка есть кнопка «Обновить».
- Ищутся только российские номера (+7). Номер передаётся сайту. Выключается в **Настройки → Пробивать номер**.

### Импорт списков

На вкладке «Списки» → **Импорт из файла** — добавляет записи в открытый список (бан или белый). Подходит TXT или CSV (в т.ч. из Excel):

```
# комментарий
8 912 345-67-89
+74951112233;Ростелеком, опрос
+7958*;виртуальные номера
```

Одна запись на строку: номер в любом формате, маска или `re:`-регулярка; через `;`, `,` или табуляцию — заметка. Заголовки и нераспознанные строки пропускаются, дубликаты игнорируются. Кодировка UTF-8 или Windows-1251.

### Перенос на другой телефон

Через вашего Telegram-бота, без своего сервера. На обоих телефонах настройте Telegram с **одним и тем же** токеном и chat_id.

1. Телефон-источник: **Настройки → Перенос на другой телефон → Отправить в бота**. В чат придёт файл с правилами и списками, бот его закрепит.
2. Телефон-получатель: **Загрузить из бота** → «Только списки» (записи добавятся к имеющимся) или «Списки и правила» (правила заменятся).

Файл из чата можно также скачать вручную и открыть через «Восстановить».

На втором телефоне с тем же ботом выключите «кнопки и команды»: Telegram отдаёт нажатие кнопки только одному из опрашивающих, и бан мог бы примениться не на том телефоне.

### Журнал

Все проверенные звонки: время, SIM, номер, имя от сети, решение и правило. Фильтры по действию и SIM, поиск. В карточке звонка — «Разбанить», «В белый список», «Найти в интернете» (отзывы о номере), «Правило по звонку». Сводка за день и неделю — над журналом. Экспорт в CSV и резервная копия правил и списков (JSON) — в настройках.

### Telegram

1. Создайте бота у [@BotFather](https://t.me/BotFather), скопируйте токен.
2. Напишите своему боту любое сообщение.
3. В приложении: **Настройки → Telegram** → вставьте токен → **Найти** (chat_id подставится сам) → включите переключатель → **Сохранить** → **Тест**.

Под сообщением о звонке — кнопки **«В бан» / «Разбанить»** и **«В белый список»**. Боту можно писать команды: `/stats`, `/last 10`, `/ban <номер или маска>`, `/unban <номер>`, `/white <номер>`, `/who <номер>` (пробить номер по отзывам), `/help`. Команды принимаются только из указанного chat_id. Телефон забирает их сам (Telegram не может «разбудить» приложение): примерно раз в 15 минут, через 2 минуты после каждого сообщения и при открытии приложения — поэтому ответ может прийти с задержкой.

Можно выбрать, о чём сообщать (сбросы и баны, dry-run, разрешённые звонки — включите, чтобы получать сводку о каждом входящем), режим «сразу» или «сводкой раз в N минут», прокси HTTP/SOCKS5. Без сети сообщения ждут в очереди. Токен хранится зашифрованным ключом Android Keystore.

## Разработка

- Kotlin, Jetpack Compose (Material 3), SQLite, WorkManager, kotlinx.serialization.
- `gradlew testDebugUnitTest` — unit-тесты движка правил, масок, форматирования.
- Эмулятор: `adb shell cmd role add-role-holder android.app.role.CALL_SCREENING com.blkdem.autoban`, затем `adb emu gsm call 89991234567`.
- Секреты (токен бота для ручных проверок) — только в `.env`, он в `.gitignore`.

### Релизная сборка

`gradlew assembleRelease` собирает сжатый R8 APK в `app/build/outputs/apk/release/`. Подпись берётся из `keystore.properties` в корне репозитория (в `.gitignore`):

```
storeFile=C:/путь/к/autoban-release.jks
storePassword=...
keyAlias=autoban
keyPassword=...
```

Без этого файла релиз собирается неподписанным. Ключ нельзя терять: обновления ставятся поверх только при подписи тем же ключом. Перед публикацией проверяйте релизный APK на устройстве — R8 может вырезать то, что создаётся через отражение (правила в `app/proguard-rules.pro`).
